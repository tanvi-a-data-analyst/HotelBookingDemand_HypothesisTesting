# SMS_RepaymentReminder_HypothesisTesting
Hypothesis testing and analysis for a microfinance repayment reminder, using simulated outcomes on Kiva loan data (from Kaggle's 'Data Science for Good KIVA crowdfunding' dataset (2018)). Borrowers are randomly assigned to a generic reminder (A) or one that names their loan officer (B), and we compare on-time repayment between the groups. The project covers power analysis, a sample ratio mismatch check, two-proportion z-tests with confidence intervals, a logistic regression testing whether the effect depends on prior contact with the officer, and a simulation showing how peeking at results inflates false positives—inspired by Karlan, Morten & Zinman’s “A Personal Touch” field experiment.
