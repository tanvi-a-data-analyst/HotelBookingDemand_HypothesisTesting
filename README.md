# What Predicts a Hotel Cancellation? A Chi-Square Test of Independence Study: 
## Testing which booking-time characteristics are associated with cancellations across ~119k hotel bookings, and digging into why "non-refundable" bookings cancel the most.

Chi-square tests of independence on 119k hotel bookings: which booking-time factors are associated with cancellation? Includes leakage checks, Cramér’s V, standardized residuals, Holm-corrected post-hoc tests, and a Cochran–Mantel–Haenszel test of why non-refundable bookings cancel most.

Dataset Used: https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand
